# Bambda Packs

These files are production-oriented starter templates for day-to-day Burp workflows.

Use them to:

- mark identifiers, sinks, roles, and workflow fields
- keep scanner-marked requests easy to compare
- reduce noise before sending the next bounded Repeater variant

Recommended order:

1. import the matching Bambda pack
2. use MCP-selected scanner context or panel-state output to confirm the target request family
3. only then import one matching custom scan check if needed

Treat these as operator aids for extraction and tagging, not autonomous logic.
